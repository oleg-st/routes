# Проверка привязки карт — 30 октября 2026

Проверены 11 активных карт, 20 игровых слоёв, 1768 размещений и 22186 точек патрулей. Источники: извлечённые `worldPosition`, `gameFrame`, исходные игровые текстуры и наши рецепты `scripts/combined-maps/`. Чужие позиции мобов не используются.

Игровые нормализованные координаты всех размещений совпали с проекцией world XYZ. Расхождения находились между старой проекцией общей карты и `artworkTransform`, с которым реально нарисована текстура.

| Карта | Результат |
| --- | --- |
| Wraithtide Vault | Проверены Lower, Upper, Jungle, Ship interior и отдельно вырезанная палуба. Проекция четырёх слоёв совмещена с текстурой; перенос палубы сохранён. |
| Empyrean Sands | Старт совпадал. На конечном участке исправлено небольшое смещение и масштаб; прежний портретный якорь Sinnari больше не нужен. |
| Ruins of Regath | Исправлена небольшая разница на обоих слоях; для подземной камеры используется полноценная игровая калибровка. |
| Stormwatch | Оба слоя совмещены с их текстурами. |
| Xul, The Blood Monolith | Все три слоя совмещены с их текстурами. |
| Silken Hollow | Лес и логово используют игровые калибровки и наши трансформации. Исключение для портрета Vexira описано ниже. |
| Godfall Quarry, Cithrel’s Fall, Scryer’s Peak, Crown of the Wild, Urrak Markets | Однослойные карты: аналогичного рассогласования не обнаружено, привязка не менялась. |

При ширине всего полотна 1500 px прежняя разница в Песках на конечном участке обычно составляла около 8 px, максимум 14 px; у портрета Sinnari около 2 px. В Regath, Stormwatch и Xul характерные расхождения составляли несколько пикселей. Это существенно меньше исходной ошибки Marrow — около 37 px при том же масштабе.

Vexira: игровой spawn проецируется севернее арены на исходной текстуре, в участок, обрезанный в общей карте. Сохранён существующий портретный якорь внутри арены рядом с черепом на нашей текстуре. Он применяется только к портрету на общей карте; world/log-координаты теперь используют точную игровую проекцию. Это исключение отображения, не исправление позиции игрового актора.

Для общей карты теперь сохраняется выбранный экспортом слой: прежняя дополнительная проверка старых границ этажей не перенаправляет уже назначенные игровые позиции на другую текстуру. Полотно, фон и координаты рисунков, сохранённых непосредственно на общей карте, не менялись. Рисунки на исходных слоях проецируются по исправленной привязке.

## Воспроизведение

```powershell
node scripts/register-map-coordinates.mjs
npm run maps
npm run build:local
npm run check
node --test tests/native-map-registration.test.mjs tests/wraithtide-projection.test.mjs tests/map-views.test.mjs tests/marker-layout.test.mjs
```

`verify-data.mjs` проверяет регистрацию при обычной сборке. Регрессионные тесты сравнивают игровые позиции, патрули, спавнеры модификаторов, точки из логов и проекцию аннотаций с фактически используемыми текстурами. Для палубы Wraithtide ожидаемые координаты независимо рассчитываются по маске и обрезке рецепта.

Все 11 карт также открыты в браузере и визуально проверены; снимки этой проверки находятся в локальной папке `tmp/map-audit/`.
